# Bunny single-cavity input

`bunny_outer.stl` is the model selected by the project author for the InFuse single-cavity experiment. It is a byte-for-byte copy of the supplied `AnyConv.com__bunny_outer.stl`, renamed to an English release filename. The geometry has not been remeshed, rescaled, or reoriented.

- Format: ASCII STL.
- Size: 9,226,152 bytes.
- Triangles: 44,644.
- Coordinate bounds: x [-40.8461, 40.8365], y [-6.2647, 56.2023], z [-39.2551, 38.2751].
- Coordinate units used by the application: millimeters.
- SHA-256: `e556e16429296d7936d32f0d5adb96b8a04db431518c3610de93ea2bb1eb0428`.

The selected single-cavity workflow corresponds to the CLI option `--mode shell`. The `fusion` workflow is not used for this experiment. The selection names the processing workflow; this preparation does not independently certify the mesh's cavity topology.

The original solid label inside the ASCII STL is retained. Git treats this supplied model as byte-preserved data so its checksum is unchanged across Windows checkouts.

The model was supplied by the project author. Its original source URL and redistribution license have not been provided; the author should record those details before public release. No Stanford or other dataset license is inferred from the filename or bunny shape.
