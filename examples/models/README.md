# Bunny single-cavity example

`bunny_outer.stl` is the bundled input for the InFuse single-cavity shell example. The mesh geometry, scale, and orientation are preserved.

| Property | Value |
| --- | --- |
| Format | ASCII STL |
| Size | 9,226,152 bytes |
| Triangles | 44,644 |
| Units | Millimeters |
| X bounds | [-40.8461, 40.8365] |
| Y bounds | [-6.2647, 56.2023] |
| Z bounds | [-39.2551, 38.2751] |
| SHA-256 | `e556e16429296d7936d32f0d5adb96b8a04db431518c3610de93ea2bb1eb0428` |

The example uses `--mode shell`. The mode selects the processing workflow; it is not an independent mesh-topology certification. The `fusion` workflow is available separately.

The ASCII STL's original solid label is retained. Git treats the file as byte-preserved data so its checksum is stable across checkouts.

## Provenance

The mesh was contributed by the InFuse project authors. No separate data license or original source URL is recorded for this model. No Stanford or other dataset license is implied by its filename or shape. Model metadata is stored in [model.json](model.json).
